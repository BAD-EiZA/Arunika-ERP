## EXACT Prisma proposal (parent: implement early + generate)

All new models deliberately use companyId scalar + @@index([companyId]); no Company relation required. Existing company FKs unaffected. DateTime SQL TIMESTAMP(3), Decimal SQL DECIMAL(18,2), Json SQL JSONB; string IDs generated by Prisma cuid().

```prisma
model TaxPeriod {
 id String @id @default(cuid())
 companyId String
 period String
 status String @default("OPEN")
 revision Int @default(0)
 snapshot Json?
 history Json?
 closedAt DateTime?
 closedById String?
 @@unique([companyId, period])
 @@index([companyId])
}
model TaxExportBatch {
 id String @id @default(cuid())
 companyId String
 period String
 revision Int
 format String
 checksum String
 payload String
 status String @default("OFFLINE_READY")
 submissionReference String?
 responses Json?
 createdById String
 createdAt DateTime @default(now())
 @@unique([companyId, period, revision, format])
 @@index([companyId])
}
model TaxPayment {
 id String @id @default(cuid())
 companyId String
 period String
 amount Decimal @db.Decimal(18,2)
 billingReference String
 bankReference String
 paymentDate DateTime
 allocations Json
 journalId String?
 notes String?
 createdById String
 createdAt DateTime @default(now())
 @@unique([companyId, bankReference])
 @@index([companyId])
}
```
